# Exam OS

A reusable ChatGPT prompt library for source-grounded university exam preparation.

## Included
- Course intake and syllabus mapping.
- Master exam tutor.
- Source audit and exact official-question extraction.
- Plain-language concept teaching and visual explanations.
- Batch practice, detailed marking and worked-problem coaching.
- Error diagnosis, honest progress tracking and mock exams.
- Last-minute cram mode and session handoff for other students.
- Guides for subject adaptation, quality control and using the workflow with another learner.
- An anonymised example based on an eight-lecture study cycle.

## Start here
1. Open [PROMPT_INDEX.md](PROMPT_INDEX.md).
2. Upload your own lecture slides, notes, tutorials and official revision papers to a fresh ChatGPT conversation.
3. Paste [prompts/01-master-exam-tutor.md](prompts/01-master-exam-tutor.md).
4. Type `START`.

The workflow keeps four measures separate: what was taught, what was understood, what the student personally attempted, and what was answered correctly. It does not count observed worked examples as independent attempts.

Course-specific content must be grounded in each student's own materials. Official questions remain verbatim; generated questions are labelled as generated.

This is a prompt toolkit, not a software agent or a guarantee of exam results.
