# Attribution and Adaptation Notes

Exam-OS adapts four behavioural principles popularised by the community project [multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills), which attributes its inspiration to [Andrej Karpathy's observations on LLM coding mistakes](https://x.com/karpathy/status/2015883857489522876).

The upstream project describes four core ideas:
1. Think before coding.
2. Simplicity first.
3. Make surgical changes.
4. Define verifiable goals and loop until they are met.

Exam-OS translates those ideas into study and source-handling behaviour:
- Think before teaching: inspect the student's actual course material and surface meaningful uncertainty.
- Simplicity first: teach the smallest coherent concept before adding extra theory.
- Surgical source handling: preserve official question text, options, labels and notation; keep generated examples separate.
- Goal-driven learning: define an independent check, practise, mark, remediate and verify.

This is an independent educational adaptation, not an official project from Andrej Karpathy, Multica, Anthropic or GitHub.

The upstream skill metadata declares MIT, and its README also states MIT, although a root-level LICENSE file was not present when checked. Exam-OS links and attributes the source and writes its educational adaptation independently rather than presenting copied upstream files as original work.

Skill-format inspiration: [Anthropic's public skills repository](https://github.com/anthropics/skills) and the [Agent Skills specification](https://agentskills.io/specification). Exam-OS uses a folder-per-skill pattern with YAML frontmatter and Markdown instructions; it does not claim to be an official Anthropic skill pack.
