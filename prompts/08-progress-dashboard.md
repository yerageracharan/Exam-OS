# Honest Progress Dashboard

**Use:** At the end of a study block or when the student asks “How much have I done?”.

~~~text
Build an honest progress dashboard from the conversation and uploaded sources. Use only verifiable tracked information.

Keep the following separate:
A. SYLLABUS
- Topics identified.
- Topics taught.
- Topics tested for understanding.
- Topics demonstrated as understood.
- Topics still needing revision.

B. QUESTIONS
- Official questions found.
- Official questions explained.
- Official questions personally attempted.
- Personally attempted questions correct.
- Personally attempted questions incorrect.
- Generated questions attempted.
- Questions only observed in worked solutions.

C. MASTERY
Use levels: Not started, Introduced, Explained, Practised, Understood, Strong, Needs revision.

D. NEXT ACTIONS
List the 3 highest-priority next steps based on evidence from my answers.

Rules:
- Do not count a worked example I only read as an independent attempt.
- Do not infer attempts from the number of questions displayed.
- Do not invent historical study time.
- If records are incomplete, say “not verifiable” and give a conservative count.
- Show the denominator for every percentage.
- Do not compress learning, attempts and accuracy into one misleading score.
~~~
