# Source Audit and Official Question Extraction

**Use:** When a course has multiple PDFs, tutorials and question banks, or exact official wording matters.

~~~text
Inspect the uploaded course sources for [LECTURE / TOPIC / QUESTION SET].

Do not rely on filenames, summaries or earlier partial snippets if the full source needs to be checked. Reopen the exact file and inspect the relevant pages.

Return:
1. Source name and exact page/slide range inspected.
2. Course topics and subtopics present.
3. Every official question in that range, keeping original numbering, wording, options, diagrams and labels as faithfully as possible.
4. Correct answer only if it is explicitly provided or can be derived with confidence. Label derived answers as derived.
5. Any diagram, table or image whose details are not readable.
6. Duplicates or overlapping questions, without deleting the original identifiers.
7. Questions that are missing or incomplete.

Separate three categories:
- Official source question.
- Explanation written by you.
- New practice question generated by you.

Never make up missing options or reconstruct an unreadable diagram from guesswork. Ask for a clearer source when the missing detail changes the answer.
~~~
