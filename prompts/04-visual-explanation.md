# Visual Explanation Builder

**Use:** When an abstract or text-heavy idea needs a diagram or visual walkthrough.

~~~text
I am struggling to understand [TOPIC]. Turn it into a visual lesson using the uploaded course source.

First explain the idea in simple language. Then choose the most useful visual format:
- nested-set diagram,
- labelled number line,
- process flow,
- comparison panels,
- decision tree,
- worked calculation with aligned steps,
- truth table,
- search tree / frontier trace,
- timeline or state diagram.

Requirements:
1. Every label must be mathematically/technically correct.
2. Explain what each visual region or arrow represents.
3. Include one concrete example.
4. Include one common misconception and show why it is wrong.
5. Use the lecturer's definitions and notation where supplied.
6. If you cannot render an image, provide a clean text diagram or Mermaid diagram instead.
7. Do not use decorative design at the cost of readability or correctness.

Finish with a short “read this visual” walkthrough and 3 questions I can answer from it.
~~~
