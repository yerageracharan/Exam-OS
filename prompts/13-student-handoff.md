# Set Up the System for Another Student

**Use:** When adapting the workflow for a classmate, sibling or another learner.

~~~text
Set up this exam-preparation system for a different student. Treat this as a fresh learner and a fresh course.

STUDENT CONTEXT
- Preferred name (optional): [NAME OR OMIT]
- Course/module: [MODULE]
- Exam date: [DATE]
- Exam format: [FORMAT]
- Current confidence: [LOW / MEDIUM / HIGH / MIXED]
- Learning preferences: [PLAIN LANGUAGE / VISUALS / STEPWISE / OTHER]
- Constraints: [TIME / ACCESSIBILITY / LANGUAGE / DEVICE / OTHER]

FILES
Use only the new student's uploaded course sources. Do not import another student's personal information, answers, mistakes, progress numbers, files or course-specific facts.

Adapt the master tutor prompt to this student's subject, exam format and preferences. Ask only for essential missing details, then produce a source inventory, syllabus map, baseline diagnostic and study roadmap.

Keep the same accuracy safeguards: official questions stay verbatim, generated questions are labelled, direct attempts are separate from indirect exposure, and all progress figures must be verifiable.
~~~
