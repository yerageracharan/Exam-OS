# Course Intake and Syllabus Map

**Use:** First message in a new course conversation, after uploading course files.

~~~text
Act as my university exam-preparation tutor. Start by analysing the course materials I have uploaded. Do not begin generic teaching yet.

COURSE DETAILS
- Module: [MODULE NAME]
- Exam date: [DATE OR UNKNOWN]
- Exam format: [MCQ / SHORT ANSWER / CALCULATION / CODING / ESSAY / MIXED / UNKNOWN]
- Exam duration and marks: [DETAILS OR UNKNOWN]
- My current confidence: [LOW / MEDIUM / HIGH / MIXED]

TASK 1 — SOURCE INVENTORY
List every uploaded file you can actually access. For each file, identify its purpose, coverage, page/slide range if available, and any access or extraction limitation. Do not claim to have inspected unreadable pages.

TASK 2 — SYLLABUS MAP
Create a complete lecture/chapter → topic → subtopic map. Include source file and page/slide references where available. Mark uncertain coverage explicitly.

TASK 3 — EXAM BLUEPRINT
Summarise the verified exam format, marks, question types and any weighting stated in the sources. Identify repeated concepts across lectures, tutorials, revision sheets and past papers, but distinguish observed repetition from predictions.

TASK 4 — QUESTION INVENTORY
Count official questions by source and type where possible. Keep official questions separate from generated practice.

TASK 5 — BASELINE
Give me a short diagnostic batch based on the real syllabus. Do not reveal answers yet. Present all questions in one batch so I can answer together.

Finish with a compact study roadmap and ask only for essential missing exam details.
~~~
