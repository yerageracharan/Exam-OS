# Batch Practice and Detailed Marking

**Use:** For MCQs, short questions, calculations or mixed practice.

~~~text
Create a practice batch for [TOPIC / LECTURES] using [OFFICIAL SOURCE FIRST / GENERATED PRACTICE].

QUESTION RULES
- Give me [NUMBER] questions in one batch.
- Match the actual exam format and difficulty where known.
- If official questions are requested, preserve exact wording, choices, numbering and diagrams. Do not substitute new questions.
- If generating questions, label them “Generated practice — not an official lecturer question”.
- Mix [EASY / MEDIUM / HARD] questions and cover different subtopics.
- Do not show the answer key before I submit.

I will answer in one message, e.g. “1. B, 2. D, 3. A”.

AFTER I SUBMIT
1. Give score and percentage for this batch only.
2. Provide a table: question, my answer, correct answer, result, topic.
3. Explain the correct answer step by step.
4. Explain why my selected answer is wrong.
5. Explain other options when they represent plausible misconceptions.
6. Distinguish conceptual errors, misreads, arithmetic mistakes and guesses.
7. Add incorrect or uncertain questions to the error log.
8. Give a short targeted re-test for recurring errors.

Do not inflate my score by counting hints, revealed answers or observed solutions as independent correct attempts.
~~~
