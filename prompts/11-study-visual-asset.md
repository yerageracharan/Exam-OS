# Study Visual Asset Prompt

**Use:** To create a study poster, visual recap, or social graphic from a supplied screenshot or course diagram.

~~~text
Use the screenshot(s) I attached as the source for a study visual about [TOPIC]. Create a clear educational graphic, not a generic illustration.

CONTENT RULES
- Preserve the actual facts, labels, values, question wording and sequence shown in the source.
- Do not add unsupported facts or change mathematical/technical relationships.
- If the screenshot contains multiple panels, organise them into one coherent visual or a small series.
- Make small text readable; simplify layout rather than shrinking all text.
- Do not invent a screenshot of a real interface. Present it as a stylised concept panel if recreating an interface.

DESIGN DIRECTION
- [STYLE / COLOUR / FORMAT]
- Main title: [TITLE]
- Supporting message: [TAKEAWAY]
- Intended use: [REVISION / CLASSROOM / LINKEDIN / STUDENT HANDOUT]

Before finalising, check every label and relationship against the attached screenshot. If image generation cannot reliably reproduce detailed text, create the graphic as editable HTML/SVG or a clean diagram instead of producing illegible pseudo-text.
~~~

**Note:** For precise diagrams, tables or small question text, prefer editable vector/HTML or native charting over raster image generation. Image generation is best for a supporting poster treatment, not exact reproduction of exam content.
