# Workflow Built from the Study Session

This repository turns a multi-lecture exam-preparation workflow into reusable templates. The useful pattern was not one giant prompt alone; it was a sequence of small prompt behaviours repeated throughout the course.

## 1. Begin with the real course files

Upload lecture PDFs, tutorials and revision papers. Build a map before teaching. This avoids learning a generic version of a topic that does not match the lecturer's notation or assessment style.

## 2. Teach in layers

For each concept, move from plain-English explanation to analogy, formal definition, visual model, worked example and exam application. If the student says “I don't understand,” change the analogy or representation.

## 3. Keep visualisation tied to learning

Use a number line for integers, nested regions for set relationships, a table for comparisons, a tree for search, or a truth table for logic. A visual should clarify the course concept, not simply decorate it.

## 4. Practise in batches

The student answers several questions in one response. This reduces interaction overhead and gives a better view of performance across a concept family.

## 5. Use official questions as the anchor

Preserve the question, options and numbering from the revision PDF. Generated questions supplement gaps; they do not replace official exam preparation.

## 6. Mark and explain, not just score

Give the correct answer, explain the student's choice, explain meaningful distractors, and record the misconception. For difficult questions, show the derivation step by step.

## 7. Track what is actually known

Keep separate counts for taught topics, demonstrated understanding, independent attempts and correct attempts. A student seeing a solved example is not evidence they can solve a new one.

## 8. Adapt the next session

Wrong answers should change the next lesson. Re-teach the underlying concept, use a different example, give a targeted re-test, and only then mark the issue as resolved.

## 9. Finish with a mock and a cram sheet

Run a realistic mixed exam, analyse errors, then create a concise final revision sheet with formulas, definitions, common traps and weak concepts.

## Important distinction

This workflow was developed from one student's learning preferences. It should be offered as a configurable system, not as a universal teaching law. Another student may prefer shorter sessions, fewer visuals, one question at a time, or a different level of detail.
