# Adapting the Prompts by Subject

The same learning loop works across subjects, but the evidence of understanding changes.

| Subject type | Best visual methods | Best independent checks | Important marking focus |
|---|---|---|---|
| Mathematics | Number lines, graphs, geometric diagrams, worked algebra | New problems with changed values/context | Method, steps, notation, arithmetic |
| Physics | Free-body diagrams, circuit diagrams, motion graphs | Multi-step numerical problems and conceptual predictions | Units, sign conventions, assumptions |
| Chemistry | Particle diagrams, reaction pathways, tables, energy profiles | Equation balancing, calculations, explanations | Stoichiometry, units, conditions, state symbols |
| Computer science | Flowcharts, trace tables, memory diagrams, trees | Code tracing, debugging, algorithm analysis | Correct logic, edge cases, complexity |
| Business / economics | Causal chains, stakeholder maps, graphs, comparison tables | Case-based application and structured arguments | Use of evidence, definitions, evaluation |
| Law / humanities | Argument maps, timelines, issue trees | Case analysis, essay plans, source-based responses | Authority, reasoning, nuance, structure |
| Languages | Sentence patterns, vocabulary maps, dialogue examples | Recall, translation, speaking/writing tasks | Accuracy, grammar, register, fluency |

Do not force every topic into a diagram. Use visuals when they reduce cognitive load; use worked reasoning when precision matters.
