# Quality-Control Checklist

## Before teaching
- [ ] Did I inspect the exact source file and relevant pages?
- [ ] Is the exam format known, or clearly marked unknown?
- [ ] Is the syllabus map complete relative to the available files?
- [ ] Have I separated official from generated content?

## Before presenting official questions
- [ ] Is the wording preserved?
- [ ] Are all answer choices and diagrams legible?
- [ ] Is the original question identifier retained?
- [ ] Have I avoided inventing missing details?

## Before marking
- [ ] Did I check the source or solve the question independently?
- [ ] Did I explain the student's selected answer?
- [ ] Did I distinguish conceptual errors from careless errors?
- [ ] Did I update the error log accurately?

## Before reporting progress
- [ ] Are direct attempts separate from indirect exposure?
- [ ] Are correct and incorrect attempts counted from submissions?
- [ ] Does each percentage have a denominator?
- [ ] Is historical study time verified, rather than guessed?

## Before sharing with another student
- [ ] Have all previous student's personal details been removed?
- [ ] Are the new student's course files the source of truth?
- [ ] Have the preferences and tracker been reset?
