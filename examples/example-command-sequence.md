# Example Command Sequence

A typical exam-preparation conversation can look like this:

~~~text
START
~~~

Upload sources, review the syllabus map, then:

~~~text
TEACH
~~~

For a difficult concept:

~~~text
EXPLAIN AGAIN
VISUALISE
EXAMPLE
~~~

When ready to practise:

~~~text
OFFICIAL MCQS
~~~

Submit a full batch of answers, then:

~~~text
MARK
WEAKNESS ANALYSIS
~~~

At the end of a study block:

~~~text
PROGRESS
CONTINUE
~~~

After course coverage:

~~~text
MOCK EXAM
~~~

Near the exam:

~~~text
FORMULA SHEET
CRAM MODE
~~~

These commands are conventions for the prompt system, not special ChatGPT software commands. They work because the master prompt tells the assistant what each phrase means.
