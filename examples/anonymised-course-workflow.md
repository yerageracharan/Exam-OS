# Anonymised Example: Eight-Lecture Exam Sprint

This example shows how the templates fit together. It is a workflow illustration, not a claim that every question in the course was independently attempted or mastered.

## Starting point

A university module had eight lecture PDFs, tutorial material and two revision PDFs. The student wanted plain-English explanations, diagrams, complete batches of MCQs, detailed marking and a formula sheet near the exam.

## How the system was used

| Stage | Prompt pattern | What it produced |
|---|---|---|
| Course setup | Course intake | Eight-lecture syllabus map and source plan |
| Concept learning | Teach one topic | Stepwise lessons for agents, search, knowledge representation and logic |
| Visual learning | Visual explanation | Number-set nesting, integer number line, rational/irrational comparison, search and logic diagrams |
| Practice | Official question extraction + batch practice | Revision questions preserved as their own source material |
| Marking | Detailed marking | Correct/incorrect results and concept explanations |
| Remediation | Error diagnosis | Re-explanations for implication, entailment, satisfiability and other weak areas |
| Tracking | Progress dashboard | Topic coverage shown separately from demonstrated mastery |
| Final revision | Cram mode | Condensed formulas, definitions, algorithm rules and logic identities |

## What made the workflow useful

- The student could say “Next” or “Continue” without restarting the whole process.
- The tutor was instructed not to skip difficult concepts or replace official questions with generic ones.
- The student answered question batches rather than being interrupted after each question.
- Confusion triggered a different explanation and another example.
- The progress tracker did not equate lecture coverage with independent mastery.

## What to improve when transferring it

For a different student, reset the course map, source files, question IDs, baseline, error log, preferences and progress. Keep the method; do not copy the previous student's content or personal record.
