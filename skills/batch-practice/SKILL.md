# Batch Practice and Marking

## Before questions
1. Identify the topic and source.
2. Prefer official previous exams, official revision papers, tutorials and lecturer examples in that order.
3. If using official material, preserve exact wording, options, numbering and diagrams.
4. Label generated questions as generated practice, not official lecturer questions.
5. Choose a batch size suitable for the request and time available.

## During the attempt
Present the whole batch together. Do not expose the answer key before submission unless requested. Provide a compact answer format such as 1. B, 2. D, 3. A.

## After submission
1. Calculate the batch score.
2. Table question ID, student's answer, correct answer, result and concept.
3. Explain each correct answer and mistake.
4. Explain plausible distractors when they reveal a misconception.
5. Distinguish wrong reasoning, careless reading, arithmetic error and correct guess.
6. Add errors to the remediation log.

## Guardrails
Verify answers against the source or derive them independently. Never infer an attempt merely because a question was displayed. Never count hints or revealed solutions as independent correct attempts.
