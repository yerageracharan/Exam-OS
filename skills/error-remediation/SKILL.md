# Error Remediation

## Goal
Find the underlying misunderstanding, teach it differently, and verify improvement with an independent re-test.

## Workflow
1. Collect exact question identifiers, submitted answers and marking evidence.
2. Classify each error: concept, notation, formula selection, calculation, misreading, reasoning, memory or time pressure.
3. Identify the root cause, not just the incorrect final answer.
4. Re-teach using a different explanation or visual.
5. Work a fresh example.
6. Give 2–4 targeted questions in one batch.
7. Re-test later with a changed context.
8. Mark the error resolved only after a correct independent response with sound reasoning.

|---|---|---|---|---|

## Guardrails
Do not label an error fixed because the student read the explanation. Preserve the original mistake in the learning record. Do not infer weaknesses from one ambiguous or poorly sourced question.
